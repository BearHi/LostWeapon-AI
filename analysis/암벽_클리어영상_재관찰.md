# 암벽 클리어영상 재관찰

대상 영상: `Videos/2026-09-06 02-48-55.mp4`

## 영상에서 확인한 것

- 플레이어는 중앙에 일정하게 놓인 발판을 계단처럼 밟지 않는다.
- 화면이 스크롤될 때마다 좌우 암벽의 표면, 턱, 벽면을 이용한다.
- 중앙은 넓은 빈 공간으로 남아 있고, 좌우 벽 사이를 크게 이동하는 장면이 있다.
- 이동 중 좌표는 발판 목록이 아니라 캐릭터의 현재 위치이므로, 좌표 샘플들을 연결해 루트를 만들면 안 된다.
- 점프+뒷굴은 높은 턱에 닿기 위한 동작이고, 낙하산은 좌우 거리가 긴 다음 암벽 표면으로 이동할 때 사용된다.

## 원본 `암벽.LMF`와의 대조

원본은 `25 x 170`이다. `8번` 충돌 타일의 위쪽 표면을 행별로 추출하면 표면이 일정 간격으로 반복되지 않는다.

- `y=24~39`: 여러 작은 턱이 가까이 모인 복합 구간
- `y=43~56`: 비교적 긴 빈 수직 구간
- `y=62~80`: 왼쪽 표면과 작은 턱이 이어지는 구간
- `y=92~120`: 좌우 표면과 내부 턱이 불규칙하게 섞인 구간
- `y=120~149`: 긴 빈 공간과 단일 측면 턱
- `y=150~166`: 정상 접근 전의 표면과 바닥 구조

## 새 맵 제작 규칙

1. 반복 계단, 균등한 착지점, 중앙 발판을 만들지 않는다.
2. 암반 충돌 외곽선을 먼저 만든다.
3. 긴 빈 구간과 턱이 밀집한 구간을 불규칙하게 섞는다.
4. 이동 루트는 점을 연결해서 정하지 않고 충돌 표면에서 추출한다.
5. 점프+뒷굴과 낙하산이 실제로 필요한 표면 관계만 남긴다.
6. 다른 표면으로 가는 쉬운 우회가 생기면 암반으로 막는다.

## 폐기한 초안

`vertical-cliff-route-v1`, `vertical-cliff-route-v2`, `vertical-cliff-surface-v3`는 균등한 점·턱을 반복해 원본 암벽 구조를 재현하지 못했으므로 새 LMF 제작에 사용하지 않는다.
