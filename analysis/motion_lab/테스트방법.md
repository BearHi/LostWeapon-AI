# 물리측정 통합01 — 한 영상으로 녹화

파일: 물리측정_통합01.LMF. 번호 1~9가 하나의 평지에 있다.
목표는 최대 높이와 거리, 점프/구르기/낙하산의 시간별 좌표를 측정하는 것이다.
자석·선풍기·스프링·얼음·위험물은 없다. 공중에 발판이나 천장도 없다.
맵의 충돌 구조와 LMF 저장은 확인했지만 게임 실행 및 실제 물리 측정은 아직 하지 않았다.

## 공통

- 캐릭터 옆 좌표와 키보드 오버레이를 켜고 가능하면 60fps로 녹화한다. 한 영상으로 1~9번을 순서대로 진행한다.
- 각 번호 위의 밝은 바닥 한 칸 근처에 선다. 좌표를 소수점까지 맞출 필요는 없다. 실제 출발 좌표는 영상에서 읽는다.
- 바라보는 방향을 먼저 맞춘 뒤 모든 키를 떼고 2초간 정지한다. 달려오면서 시작하지 않는다.
- 각 실험은 같은 조건으로 2회. 착지 후 모든 키를 떼고 2초 정지한 다음 원래 번호로 돌아온다.
- 일반 점프는 ↑만 눌렀다 뗀다. 구르기를 발동하려면 그 다음 별도로 →＋↑를 누른다.
- 점프 후 구르기 시점은 일반 점프의 상승이 멈추기 직전으로 맞춘다. 정확한 프레임을 외울 필요는 없고 실제 입력 시점을 영상에서 측정한다.
- 모든 이동 실험은 오른쪽으로 진행한다. 앞굴은 오른쪽을 본 상태, 뒷굴은 왼쪽을 본 상태에서 발동한다.
- `해제`는 구르기가 발동하면 ↑와 → 모두 떼기. `유지`는 ↑만 떼고 →는 착지까지 누르기.
- 낙하산은 공중에서 접지 않는다. 낙하산을 편 후 구르기를 추가하지 않는다.
- 다음 번호를 지나 착지해도 정상이다. 번호는 구역 경계가 아니다. 맵 끝에 닿았다면 왼쪽의 넓은 위치로 옮겨 같은 실험을 녹화한다.
- 실수하거나 다른 동작이 나와도 영상을 자르지 말고 다시 시도한다. 영상만 보내면 좌표표는 분석 측에서 만든다.

## 순서

| 번호 / 출발 x 부근 | 보는 방향 | 정확한 입력 |
|---|---|---|
| 1 / 14 | 오른쪽 | ↑ 점프 후 모든 키 떼기. 착지까지 좌우·구르기·C 입력 없음. |
| 2 / 36 | 오른쪽 | ↑ 점프 후 ↑를 떼고, 발이 뜬 다음 →를 착지까지 유지. 구르기가 나오면 다시 시도. |
| 3 / 58 | 왼쪽 | 지상에서 →＋↑로 뒷굴 → 발동 후 두 키 모두 떼기. 먼저 점프하지 않음. |
| 4 / 80 | 왼쪽 | ↑ 점프 후 떼기 → 최고점 직전 →＋↑ 뒷굴 → 두 키 모두 떼고 착지. |
| 5 / 102 | 왼쪽 | 4번과 같되 뒷굴 발동 후 ↑만 떼고 →는 착지까지 유지. |
| 6 / 124 | 오른쪽 | ↑ 점프 후 떼기 → 최고점 직전 →＋↑ 앞굴 → 두 키 모두 떼고 착지. |
| 7 / 146 | 오른쪽 | 6번과 같되 앞굴 발동 후 ↑만 떼고 →는 착지까지 유지. |
| 8 / 168 | 오른쪽 | ↑ 점프 후 떼기 → 최고점 직전 C로 낙하산을 펴면서 → 누르기 → 착지까지 → 유지, 낙하산은 접지 않음. |
| 9 / 190 | 왼쪽 | 5번처럼 점프 후 뒷굴하고 → 유지 → 뒷굴 뒤 상승이 끝날 무렵 C → 착지까지 → 유지, 낙하산은 접지 않음. |

4번에서는 추가로 두 번만 더: `발이 뜨자마자 뒷굴` 1회, `상승 중간에 뒷굴` 1회. 두 경우 모두 발동 후 방향키를 뗀다. 이 기록으로 뒷굴 시점과 상승량의 관계를 비교한다.

## 결과의 해석

- 기존 6개 소형맵 결과: 점프 후 공중 뒷굴, 발동 후 방향키 해제. 높이08 성공, 나머지 실패. 사용자는 높이10/12/14 실패를 높이 부족으로 설명했다.
- 위 성공·실패를 방향키 유지 실험과 합치지 않는다.
- 이번 영상에서 출발/점프/구르기/낙하산/최고점/착지 프레임, 캐릭터 옆 원문 좌표, 키 상태를 함께 기록한다.
- 좌표의 콜론 뒤 숫자 단위는 영상과 타일 경계에서 확인한 후 변환한다. 화면 하단 고정 위치 표시는 측정에 사용하지 않는다.
- 발판 착지·천장 충돌·경사·기믹 힘은 이 평지 실험만으로 검증되지 않는다. 이 결과로 맵 전체 클리어를 단정하지 않는다.
