# 이동범위 맵 제작 기준

영상 좌표는 캐릭터 중심 좌표와 실제 충돌면 좌표가 완전히 같지 않으므로, 수치를 절대값으로 쓰지 않는다. 대신 각 동작을 세 구간으로 나눈다.

| 동작 | 맵에 적용하는 방식 |
|---|---|
| 일반 점프 | 최고점에 딱 닿는 발판은 검증용, 그보다 1칸 낮은 발판은 안전 구간 |
| 앞구르기 | 지뢰·낮은 장애물을 통과하는 낮은 루트에만 사용 |
| 뒷구르기 | 긴 수평 간격에 사용하되, 착지면을 반드시 한 칸 이상 확보 |
| 낙하산 | 수직 낙하 제어용. 선풍기와 자석을 동시에 겹치지 않음 |
| 자석 | 기본 동작의 보정값으로만 사용. 자석만 믿어야 하는 점프는 별도 테스트 구간 |

## 제작 규칙

1. 새 구간은 먼저 일반 점프만으로 도달 가능한지 확인한다.
2. 일반 점프로 불가능하면 앞구르기 또는 뒷구르기 중 하나만 요구한다.
3. 한 구간에서 자석·선풍기·얼음을 동시에 요구하지 않는다.
4. 실패 시 아래로 떨어져 이전 발판으로 돌아갈 수 있게 한다.
5. 루트의 모든 발판은 좌표상 도착점이 아니라 실제 발이 설 수 있는 충돌면을 기준으로 잡는다.

다음 맵부터는 이 기준으로 먼저 도트 미리보기를 만들고, 루트의 각 연결부에 동작 종류를 표시한 뒤 LMF를 생성한다.
