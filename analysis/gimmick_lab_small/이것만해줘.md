# 간단03 — 이것만 해줘

캐릭터 옆 좌표와 키보드 표시를 켜고 한 영상으로 찍어줘.

1. 바닥 숫자 **1**에서 **3초 앉았다 점프뒷굴**, 두 번.
2. 바닥 숫자 **2**에서 **똑같이**, 두 번. 1번과 같은 방향으로 해줘.
3. 오른쪽 사다리로 올라가 **얼음에서 미끄러지다 점프뒷굴**, 두 번.

낙하산은 이번엔 안 펴도 돼. 실수하거나 자석에 걸려도 영상 자르지 말고 남겨줘.
좌표나 시간을 정확히 맞출 필요 없어. 실제 좌표·입력 시점은 영상에서 읽을게.

자석은 하나만 있으며 바닥에서 띄워 두었어. 1·2번은 자석과의 위치 차이를 비교하는 자리야.
여러 자석 힘의 조합은 이번 실험에서 제외했어.
파일 구조·배치 검사는 완료했고 실제 게임 동작은 아직 시험 전이야.
