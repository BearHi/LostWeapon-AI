# 로스트웨폰 유즈맵 역설계 통합 분석

## 1. 맵의 본질

암벽·암벽11은 발판을 많이 놓은 점프맵이 아니다. 암반을 먼저 채우고, 플레이어가 지나갈 수 있는 빈 공간을 깎아 만든 단일 상승 통로다. 따라서 미니맵에서 중요한 것은 장식 타일 수가 아니라 검은 빈 공간의 연결 형태다.

각 구간은 다음 발판 하나만 보이게 설계된다. 위쪽에 다음 발판이 여러 개 보이면 우회가 생기고, 아래에서 바로 올라가는 지름길이 생긴다. 좋은 구간은 실패하면 아래의 이전 발판으로 떨어지며, 완전히 막히거나 바닥으로 초기화되지 않는다.

## 2. 충돌과 공간

- 일반 블록은 위에 설 수 있고 벽으로 작동한다.
- 세로 빈 공간 1칸은 일반 이동으로 통과하지 못한다.
- 세로 빈 공간 2칸 이상이 기본 통로다.
- 미끄럼 경사, 자석, 특수 자세가 있으면 1칸 공간도 예외적으로 진입할 수 있다.
- 경사 블록은 계단 장식이 아니라 걸어서 올라가는 실제 충돌면이다.
- 큰 텍스처 면은 배경일 수 있으므로 미니맵의 큰 색 덩어리를 전부 벽으로 해석하면 안 된다.

## 3. 이동 모델

플레이어 위치는 단순한 셀 이동이 아니라 연속 좌표다. 점프는 초기 수직속도와 중력의 합이고, 좌우 입력은 수평속도를 바꾼다. 앞구르기와 뒷구르기는 같은 점프가 아니다.

- 일반 점프: 가장 높은 턱을 판단하는 기준 동작.
- 앞구르기: 몸의 충돌 높이가 낮아져 지뢰 같은 낮은 장애물을 통과할 수 있지만 수평 도달거리는 짧다.
- 뒷구르기: 더 긴 수평 이동과 낮은 자세를 얻는 주 이동기다. 높은 턱의 끝에 아슬아슬하게 닿도록 배치된다.
- 낙하산: 상승기가 아니라 하강속도를 줄여 공중에서 착지 위치를 조절하는 도구다.
- 미끄럼 블록: 착지 후 수평속도가 남아 다음 점프 출발점이 달라진다.

따라서 거리만 셀 것이 아니라 시작 자세, 이동 방향, 착지 높이, 착지면 폭을 함께 봐야 한다.

## 4. 자석과 선풍기

자석은 순간이동이나 고정 속도가 아니라 이동 중 계속 더해지는 방향성 힘으로 보는 것이 맞다. 같은 점프라도 자석과의 상대 위치가 바뀌면 궤도가 달라진다. 좌우 자석은 방향키를 누르는 동안 효과가 약해지거나 상쇄될 수 있다.

선풍기는 낙하산 상태에서 수직 상승력을 더한다. 위쪽 자석의 영향권에 놓이면 상승과 좌우 이동이 함께 바뀐다. 따라서 선풍기와 자석을 겹쳐 놓은 구간은 일반 점프 기준으로 계산할 수 없고, 회복 가능한 넓은 착지면이 필요하다.

## 5. 위험물 배치

- 가시는 무적시간을 무시하므로 공중에 임의로 띄우지 않고 실제 접근 타이밍에 맞춘다.
- 지뢰와 다이너마이트는 자세별 충돌 높이를 시험하는 장애물이다.
- 들락가시는 같은 타이밍을 반복하므로 간격보다 통과 시점과 대기 발판이 중요하다.
- 용암은 길을 장식하는 바닥이 아니라 실패 시 진행을 끊는 경계다. 구르기로 통과할 수 있는 구간과 즉시 초기화되는 구간을 구분해야 한다.
- 스프링은 위 4칸이 확보되지 않으면 상승이 막힌다.

## 6. 좋은 암벽맵의 생성 순서

1. 암반 외곽과 목표 높이를 정한다.
2. 시작점에서 정상까지 단 하나의 빈 공간 연결선을 만든다.
3. 연결선의 각 꺾임에 실제 발판을 하나씩 남긴다.
4. 발판 사이를 일반 점프·앞굴·뒷굴 중 하나로만 연결한다.
5. 모든 통로의 세로 여유가 2칸 이상인지 확인한다.
6. 루트 밖의 빈 공간은 암반으로 막아 중간 직행을 제거한다.
7. 실패 시 이전 발판으로 돌아오는 낙차를 남긴다.
8. 마지막에만 가시·얼음·자석 같은 기믹을 넣는다.

이 순서를 지키면 장식 때문에 길이 생기거나, 발판을 많이 깔아 노가다맵이 되는 문제가 줄어든다.

## 7. 영상과 수정맵에서 얻은 결론

### 좌표 샘플

영상에서 읽힌 캐릭터 옆 좌표 샘플은 다음과 같다. 표기 형식은 영상에 표시된 두 줄을 그대로 적은 것이며, 화면 하단의 고정된 현재 위치 표시는 제외했다.

| 영상 | 시점 | 표시 좌표 |
|---|---:|---|
| 암벽 수정 클리어 | 0초 | `9:17.000 / 239:0.000` |
| 암벽 수정 클리어 | 1초 | `15:9.000 / 234:5.200` |
| 암벽 수정 클리어 | 2초 | `16:17.000 / 225:4.800` |
| 암벽 수정 클리어 | 3초 | `21:29.000 / 220:6.400` |
| 암벽 수정 클리어 | 10초 | `22:3.000 / 186:12.000` |
| 암벽 수정 클리어 | 91초 | `26:17.000 / 8:15.400` |
| 짧은 동작 테스트 | 약 6초 | `30:14.000 / 21:0.000` |
| 짧은 동작 테스트 | 약 12초 | `34:24.000 / 15:18.400` |
| 짧은 동작 테스트 | 약 18초 | `30:24.000 / 17:24.750` |
| 짧은 동작 테스트 | 약 24초 | `49:26.000 / 31:7.200` |

이 값들은 서로 다른 동작과 자석 배치가 섞인 샘플이라 최대 이동거리로 바로 쓰면 안 된다. 하지만 암벽 수정 클리어 영상에서는 첫 3초 동안 두 번째 좌표가 `239.0 → 220.6`으로 크게 변하고, 이후 10초까지 `186.12`까지 내려간다. 즉 짧은 시간의 큰 수직 변화는 일반 보행이 아니라 점프·구르기·낙하가 섞인 구간으로 분리해 분석해야 한다.

성공한 `암벽수정1.LMF`는 발판을 늘린 것이 아니라, 처음과 두 번째 구간의 높이·수평 간격을 실제 조작 가능한 범위로 낮추고, 우측 중간 발판을 연결해 연속 실패를 막았다. 영상에서 좌표가 위로 진행하는 동안 중간 발판에서 잠시 멈추고 다시 점프하는 패턴이 반복되므로, 매 발판을 최대거리로 연결하는 것이 아니라 짧은 성공 구간과 아슬아슬한 구간을 교차해야 한다.

앞으로 제작할 때는 이 문서를 기준으로 먼저 충돌 루트를 검증하고, 그 다음 도트와 LMF를 만든다.
