# 물리측정 기믹통합02

한 파일에 9개 방. 아래 1번에서 시작하고 왼쪽 사다리로 각 방에 들어간다.
바닥 속 밝은 숫자가 방 번호다. 사다리는 실험실 이동에만 사용한다.
첫 녹화는 1~6번부터. 7~9번은 같은 파일에 준비해 둔 추가 실험이다.
성공/실패를 가르는 목적지가 없는 측정용 맵이다. 높이와 궤적 자체를 기록한다.

## 촬영 공통

- 캐릭터 옆 좌표와 키보드 오버레이를 켜고 가능하면 60fps로 한 영상에 녹화한다.
- 각 조건은 2회. 결과가 크게 다르면 한 번 더. 실수한 장면도 자르지 않는다.
- 방에 들어가 번호가 보이는 곳에서 잠시 멈춘 후 시작한다.
- 대기 0초는 접촉 직후를 뜻한다. 1초/3초는 대략 맞춰도 된다. 실제 시간은 영상에서 측정한다.
- 일반 점프: 좌우 입력을 떼고 ↑만 눌렀다 떼기. 이후 별도 지시가 없으면 키를 뗀다.
- 점프+뒷굴: 왼쪽을 본 상태에서 ↑ 점프 → ↑를 뗐다가 상승이 끝나기 직전 →+↑로 뒷굴.
  이후 ↑는 떼고 →는 착지까지 유지한다. 실제 발동 시점을 영상으로 기록한다.
  내리막에서 방향이 바뀌었다면 평소 사용하는 방향 전환으로 오른쪽 뒷굴을 한다.
  이 추가 입력도 그대로 녹화하며 일반 점프 측정과 구분한다.
- 낙하산은 해당 실험에서만 C로 펴며 공중에서 접지 않는다.
- 앉기는 평소 사용하는 앉기 입력을 쓴다. 자석 위에서 앉는 상태와 서 있는 상태를 구분한다.
- 자석 위에서 위치가 밀리면 억지로 같은 좌표에 고정하지 않는다. 계속 녹화한다.
  움직임 때문에 위치가 달라진 시험은 같은 자리의 대기시간 비교와 구분해 분석한다.
- 사다리·벽·천장에 닿은 시도는 계속 녹화하되 자유비행 궤적 측정에서는 제외한다.
- 매 시도 같은 방향에서 접근한다. 정지 몇 초만으로 중력/속도 상태가 초기화된다고 가정하지 않는다.

## 1차 촬영: 1~6번

| 방 | 기준 좌표/위치 | 할 동작 |
|---|---|---|
| 1 평지 | x=72 부근, 바닥 y=576 | 서서 일반 점프 2회 → 3초 앉았다 일반 점프 2회 → 점프+뒷굴 2회. |
| 2 가로 자석 36 | 자석 x=72, y=511 | 자석 위에서 앉아 접촉 직후/1초/3초 각각 일반 점프 2회. 다음으로 서서 3초 후 일반 점프 2회. 마지막으로 앉아 3초 후 점프+뒷굴 2회. |
| 3 반대 가로 자석 37 | 자석 x=72, y=447 | 2번과 같은 순서·바라보는 방향·입력으로 반복. |
| 4 평면 얼음 13 | 얼음 x=40~104, 바닥 y=384 | x=72 부근에서 일반 점프 2회. 이어 x=56 부근부터 오른쪽으로 이동하여 x=64 부근/88 부근에서 일반 점프 각 2회. 좌우 입력을 떼고 ↑를 눌러 구르기와 구분. |
| 5 일반 내리막 20 | 높은 시작면 x=48~51, y=308; 경사 x=52~63 | 높은 면 x=50 부근에서 출발해 오른쪽으로 내려가며 x=56 부근/61 부근에서 일반 점프 각 2회. 마지막으로 같은 출발에서 x=61 부근 점프+뒷굴 2회. |
| 6 삼각 얼음 25 | 높은 시작면 x=48~51, y=244; 경사 x=52~63 | 5번과 같은 출발 위치·진행 방향·점프 위치로 반복. 추가로 경사에 진입한 뒤 방향키를 떼고 미끄러지다가 x=61 부근 일반 점프 2회. |

자석이 밟히지 않는다면: 바로 옆 바닥에서 앉아 같은 순서를 진행하고 그 장면을 남긴다.
위에 섰던 시험과 옆에 있던 시험은 합치지 않는다. 접촉 형상 자체가 측정 대상이다.

5·6번의 경사는 모양과 높이가 같고 타일만 다르다. 점프 위치마다 출발 높이가 달라지므로
최고점의 절대 y가 아니라 **점프 시작 좌표에서 얼마나 올라갔는지**를 비교한다.
서로 다른 위치에서 점프한 결과만으로 시간 누적이 원인이라고 단정하지 않는다.

1~6번을 끝내면 1번으로 돌아가 일반 점프 2회와 점프+뒷굴 2회를 더 한다.
처음과 높이가 달라지면 상태가 남는지, 주변 자석의 영향인지 추가로 분리한다.
기존 무기믹 `물리측정_통합01.LMF`의 기록도 대조한다.

중간 바닥이나 천장에 닿으면 입력을 멈춰 회수한다. 천장에 닿은 높이는 최대 도달 높이가 아니라 하한값으로 기록한다.
자석+얼음, 자석+선풍기 조합은 단독 결과를 보고 필요한 조건만 다음 판에서 추가한다.

## 분석 기준

현재 관찰: 사용자는 자석에서 앉아 기다리거나 얼음에서 미끄러지면 점프가 높아지는 현상을 보고했다.
미확정 원인: 점프 초기속도 변화, 유효 중력 변화, 경사 접촉 중 속도 유지/전환, 다른 내부 상태의 지속.
이들은 후보 설명이며 실제 게임 구현이라고 주장하지 않는다.

각 시도에서 접촉 시작/앉기/점프/구르기/C/최고점/착지 프레임과 캐릭터 옆 원문 좌표를 기록한다.
좌표 콜론 뒤 값은 검증된 타일 단위로 변환한 뒤 계산하며 0.xx칸으로 임의 해석하지 않는다.
짧은 구간의 위치 변화로 상승속도를 추정하고, 여러 프레임을 함께 맞춰 중력 변화와 구분한다.
최고점·상승시간·하강속도·이탈 후 궤적을 함께 비교한다.
공중 구르기처럼 힘이 바뀌는 프레임을 사이에 두고 하나의 포물선으로 맞추지 않는다.
일부 시도로 모델을 맞춘 뒤, 남겨둔 반복 시도를 예측해 오차를 확인한다.

이 맵의 64칸 층간 간격이나 암반은 자석 영향 차단을 보증하지 않는다.
무기믹 기록과 이 맵 1번 결과부터 비교하여 영향이 있으면 배치를 조정한다.
현재는 파일 구조와 공간을 검사한 측정장치이며 게임 물리 검증/클리어 인증 결과가 아니다.

## 타일 번호 정정

에디터는 16진수, 분석 스크립트의 기본 정수 출력은 10진수다.

| 에디터 표시 | LMF 정수 | 실제 리소스 그림 |
|---|---:|---|
| 13 | 19 | 사각 얼음 |
| 1B | 27 | 한쪽 삼각 얼음 |
| 25 | 37 | 반대쪽 삼각 얼음 |
| 20 | 32 | 일반 벽돌 내리막 삼각형 |
| 33 | 51 | 선풍기 |
| 34~37 | 52~55 | 자석 네 방향 |
| 52 | 82 | 물처럼 보이는 파란 타일 |

그림은 `analysis/tilemap.json`의 에디터 리소스 매핑과 실제 bitmap을 대조했다.
LMF 82의 충돌·수영 여부는 이번 측정 대상에서 제외했으며 장식이라고 단정하지 않는다.
사용자가 말한 에디터 27과 LMF 정수 27은 서로 다른 타일이다.
