# 이번 주 실행과 다음 설계

## 현재 진단

2026-09-19 확인: 공유 모델 자료 75,333건, 마지막 실행 15회 모델 승격 0회.
제외 맵 위치 오차 56.83px (상수 기준 86.73px), 위험 Brier 0.03736 (상수 기준 0.03225, 낮을수록 좋음).
고정 500개 후보 비교에서는 위험 2.6%로 좋아졌지만 더 넓은 검증은 통과하지 못했다. 기존 active 모델은 보존되었다.
9×9 한 장으로 최대 64결정 뒤 결과를 예측하면 시야 밖 지형과 시간에 따른 상태 변화가 섞인다.
이는 실패 원인 후보이며, 짧은 예측과 동일 데이터 비교로 검증해야 한다. 자료량만 늘리면 해결된다는 근거는 없다.
현재 신경망은 행동 결과 예측기다. 사람을 모방하는 정책이나 새로운 맵을 푸는 완성된 두뇌가 아니다.

## 이번 주 사용

- `이번주_자료수집.bat`: 모델 재학습 없이 새 폴더에서 최대 8결정 행동을 native 실험한다. 한 번 최대 1시간/1라운드/맵당32건. 누적 약8천 건 예산에 도달하면 추가 실행을 거절한다. 기본 23맵을 전제로 한 보수적인 한 라운드 예약 방식이다. 시작 경로 복원 자료 등으로 총 행 수는 예산과 약간 다를 수 있다.
- `내플레이_기록시작.bat`: 실행 후 120초 내 Client 창 선택. 한 번 최대30분 또는256MiB. 전체 약2GiB 한도. 상태/게임키는 최소20ms 간격, 주변 실제4개 지형그리드는 최소100ms 간격, 물체 목록은 최소10초 간격. 처리시간이 더해지므로 정확한 주기가 아니다.
- 게임 중 F6=방금 좋은 구간 표시, F7=실수 표시, F9=일시정지/재개. 표시는 선택사항이며 성공 정답 판정이 아니다. 게임 채팅 중에는 F9로 멈춘다. 다른 창에서는 입력을 기록하지 않는다. 프로그램은 게임 메모리를 읽고 키를 관측할 뿐 입력을 보내지 않는다.
- `이번주_중지.bat`: 이번 주 수집/기록 종료 요청. 기존 장시간 학습을 멈추는 파일은 `로컬물리_훈련중지.bat`이다.
- `이번주_결과정리.bat`: 언제든 요약 재생성. 수집/기록 종료 때도 자동 생성된다.
- 저장: `checkpoints/week_review_20260919/REVIEW.md`, `sessions.jsonl`, `human/*.jsonl`, `short_native/*.sqlite3`.
- 기존 `공유두뇌_학습시작.bat` / `로컬물리_훈련시작.bat` 장시간 재학습 대신 위 새 실행 파일을 사용한다. 기존 자료는 지우지 않는다.

반복 실행은 횟수 제한 내에서 가능하지만 이번 주 수집도 성능 향상을 보장하지 않는다. 사람 시범 수집을 우선한다.
짧은 수집 DB는 아직 공유 모델 학습에 자동 합치지 않는다. 다음 검토에서 분포/라벨을 먼저 검사한다.
녹화는 영상이 아니라 숫자 로그다. 실시간 프로세스 읽기는 원자적 snapshot이 아니며 키도 game tick과 동기화되지 않는다.
Client 실제 플레이에서 새 기록 기능의 지연/맵 식별/지형 의미를 검증하는 작업은 남아 있다.
첫 기록 후 요약에서 sample/terrain이 존재하고 terrain_unavailable이 반복되지 않는지 확인한다.

## 다음 주 목표 구조

1. 사람 시범 시간 간격, 지형 읽기 소요, 맵 식별, 누락, 성공/실패 구간을 먼저 검사한다. 기록된 키를 즉시 정답 action으로 취급하지 않는다. 가능한 구간은 native 재현과 비교한다.
2. 최근 여러 관측 + 9×9 + 속도/자세/행동 이력을 입력하고, 2~8결정의 짧은 기술과 종료 조건을 학습한다. 매번 재관측하여 교정한다. 초기에는 검증된 구간의 모방 학습, 결과 예측은 보조 목표로 둔다.
3. 상위 선택기는 방문 지형/실패/도달 가능한 지점을 기억하고 다음 소목표와 기술을 고른다. 9×9만으로 보이지 않는 맵 전체의 최적 행동은 보장할 수 없다.
4. 용암은 타일만 보고 금지하지 않는다. 구르기/넘어짐/속도/체력과 실제 다음 상태를 함께 본다. 의도적인 피격은 상대/물체 타이밍을 재현할 수 있는 자료에서만 비교한다.
5. 기존 네 개 제외 맵은 모델 선택에 이미 사용했으므로 최종 미지 맵 시험으로 재사용하지 않는다. 별도 새 맵과 시작 상태에서 목표 달성/리스폰/시간을 평가한다.

기존 물리와 데이터는 재사용한다. 사람의 모든 유즈맵 이해를 목표로 한 번에 다시 만들지 말고, 한 기술이 다른 지형에서도 재현되는지부터 확인한다.
