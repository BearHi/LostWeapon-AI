# 로컬 학습 설계

학습 실행에는 ChatGPT/API 토큰을 사용하지 않는다. `NativeTrainingAPI`와 로컬 Python/PyTorch 프로세스가 CPU/GPU에서 직접 episode를 반복하고 체크포인트를 디스크에 저장한다.

## 목표까지 벽이 막힌 맵

깃발과의 직선거리만 보상으로 쓰지 않는다. 바로 옆 깃발 사이에 벽이 있으면 직선거리 보상은 벽에 붙어 있는 잘못된 행동을 강화하기 때문이다.

초기 보상은 다음으로 제한한다.

- 원본 goal 접촉: 큰 양의 보상
- 원본 사망/리스폰: 음의 보상
- 매 tick: 작은 시간 비용
- 처음 방문한 `(x, y, movement state)`와 새 통로: 탐색 보상
- 같은 막힌 상태 반복: 반복 비용

탐색 중 발견한 상태들을 그래프로 연결하고, 실제로 실행에 성공한 edge만 기록한다. 목표에 닿는 경로가 한 번 발견된 뒤에는 그 그래프의 최단거리 감소를 보조 보상으로 사용한다. 따라서 벽 반대편으로 돌아가는 동선, 사다리, 스프링, 낙하산, 자석 같은 우회도 실제 성공한 상태 전이로 학습된다.

## 학습 순서

1. 훈련용 작은 맵에서 한 틱 입력과 짧은 입력 묶음의 기술 정책을 학습한다.
2. 임의 LMF에서 새 상태/통로를 찾는 탐색 정책을 학습한다.
3. 발견한 상태 그래프 위에서 목표 경로를 선택한다.
4. 선택한 경로의 중요한 분기와 최종 주행을 원본 x86 oracle로 다시 검증한다.
5. 죽거나 막힌 구간만 재학습하고 성공 체크포인트를 누적한다.

## 물리 확정 전후

`native_env.py`에 Gym 형태의 `reset / step / observation / reward / done` 환경을 연결했다. 관측은 player 원본 상태, 가장 가까운 목표의 상대 위치, 주변 9×9 네 개 collision grid이며, 19개 입력 조합을 원본 x86에 그대로 전달한다. `train_local_dqn.py`는 설치된 로컬 PyTorch로 DQN을 학습하고 `checkpoints`에 상태를 저장한다. ChatGPT/API 토큰은 쓰지 않는다.

훈1 첫 실행은 `학습시작_훈1.bat`을 더블클릭한다. 임의 사용자 맵은 `학습시작_맵선택.bat`을 더블클릭한 뒤 LMF를 고른다. 콘솔에 episode별 reward/success가 나오고 10 episode마다 `checkpoints` 폴더의 체크포인트가 갱신된다. 두 배치파일은 Windows `cmd.exe`에서 줄이 합쳐지지 않도록 CRLF로 저장한다. 물리 parity가 확정되지 않은 기믹 맵은 해당 결함까지 함께 학습되므로, 확인된 기믹부터 curriculum에 추가한다.

## 물리 수정 후 학습 보존

체크포인트에는 관측 항목 이름, 원본 물리 코드 fingerprint, 캡처 snapshot SHA-256, LMF SHA-256을 함께 저장한다. 물리 코드나 캡처가 바뀌면 기존 정책 가중치는 이어받되 이전 optimizer 누적값은 버린다. 관측 항목이 추가되면 이름이 같은 입력 열의 가중치만 새 신경망으로 옮긴다.

각 episode는 체크포인트 옆 `*.episodes.jsonl`에도 맵 hash와 run-length 압축 입력 행동열로 저장된다. 이 기록은 예전 물리의 다음 상태값을 정답으로 고정하지 않는다. 나중에 중력이나 충돌 수정이 생기면 같은 행동열을 수정된 원본 오라클에서 다시 실행해 경험을 재생성할 수 있다.
