# 깃발 헬퍼 훈련 기록 보존·구조 감사 — 2026-09-17

## 중지 시점의 사실

- 훈1: 100에피소드, `goal:true` 96회. `checkpoints/route_rule_helper.json`과 `.episodes.jsonl` 보존.
- 훈2~17: 각 20에피소드. 훈18: 10에피소드 후 중지. 이 순회 합계 390에피소드, `goal:true` 163회. 전체 합계 490에피소드, 259회.
- `checkpoints/route_curriculum/hun_status.json`은 `stopped`, 중지 표식은 존재하고 훈련 프로세스는 없었다. 훈19·20은 아직 기록이 없다.
- 훈2~훈18의 원본 JSONL은 성공·실패·시작 지역 복귀 횟수·행동열을 모두 보존한다. 실패 결과도 삭제하거나 성공으로 바꾸지 않는다.
- `goal:true`는 원본 x86 실행 후 깃발 설정 영역 도달 판정이다. 별도 Client 깃발 이벤트 신호나 일반 Client 화면의 클리어 판정으로 부르지 않는다.

## 발견한 구조적 실수와 수정

1. 앞선 중간점검에서 실패 맵만 보고 중지를 권했다. 여러 맵에서 이미 성공이 축적됐고, 훈련 시간과 기록의 가치를 충분히 확인하지 않았다.
2. 기존 훈련기는 성공 행동열을 JSONL에 썼지만 최선 경로로 재사용하지 않았다. `best_recorded_route`로 과거 기록에서 복귀 없는 최단 성공열을 복원하고, 다음 실행의 첫 에피소드에서 native 재생한 뒤 짧은 구간을 변형하도록 수정했다. 더 빠른 복귀 없는 성공에 추가 보상 10점을 준다.
3. 예전 `checkpoints/physics_route_library.json`을 새 훈련기가 읽지 않았다. 훈5 127결정, 훈6 65결정, 훈12 122결정 경로를 현재 오프라인 native 환경에서 각각 재생해 목표 영역 도달을 확인했다. 다음 실행에서 이보다 느리거나 성공 경로가 없는 맵은 예전 후보를 먼저 재생한다.
4. 시작 지역 복귀가 섞인 성공열을 빠르다는 이유만으로 최선 경로로 삼으면 사용자 규칙에 어긋난다. 현재 최선 경로 선택과 갱신에서 `return_to_start > 0`을 제외한다. 원본 성공·실패 로그는 그대로 둔다.
5. 앞으로 복귀 없는 성공열의 발판 전이를 `checkpoints/route_curriculum/physics_transitions.json`에 별도 보존한다. 이 조각을 새 맵에서 자동으로 신뢰하거나 사용한다는 뜻은 아니다.
6. 재개 시 덮어쓰는 체크포인트의 이전 바이트를 `pre_resume_snapshots/`에 자동 보관하도록 했다. 중간에 멈춘 미완료 에피소드는 `interrupted`로 기록하고 완료 횟수·성공률에 넣지 않는다.

## 현재 보존 위치

- 작업 전 기록의 별도 사본: `checkpoints/route_preservation/20260917_210550/`.
- `manifest.json`에 44개 파일의 크기와 SHA-256이 있다. 복사 직후 각 파일의 바이트가 원본과 같은지 확인했다.
- 기존 `physics_first_local/`, 다른 DQN·전투 체크포인트와 사용자 LMF·snapshot은 이번 수정에서 교체하거나 삭제하지 않았다.

## 남은 한계

- 훈5·훈6.5·훈12 등은 새 규칙 정책의 첫 20회에서 성공률이 낮거나 0이었다. 예전 경로의 현재 native 재생 가능성과 새 정책의 독립 판단 성공은 서로 다른 사실이다.
- 상황 표현은 아직 지형·기믹·물리 상태를 충분히 담지 못한다. 성공 경로 재생과 변형 탐색을 추가했어도 모든 맵 일반화가 입증된 것은 아니다.
- 시작 지역 복귀 횟수는 raw49 근접과 위치 급변에 따른 추정이다. 실제 리스폰 신호와의 일치를 추가 검증해야 한다.
- 사용자 직접 조작, 미니맵 상대 추적, 전투 명중·회피 보상, 일반 Client 자동 조작은 이 훈련기에 아직 연결되지 않았다.

다음 작업자는 이 문서·기존 JSONL·별도 백업을 먼저 확인하고, `goal:true`와 독립 일반화 성능을 구분한다. 사용자가 훈련을 실행하며, 진단이나 코드 수정이 훈련 재시작을 암묵적으로 뜻하지 않는다.
