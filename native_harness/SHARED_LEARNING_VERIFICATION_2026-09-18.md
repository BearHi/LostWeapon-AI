# 공유 학습 검증 기록

- 점검 당시 native 시험 30,184개, 상황/기술 항목 28,150개. 그중 93.7%가 1회 관측이었다.
- 기존 자료 중 길이/상태 조건을 만족한 29,933개를 새 모델의 감독 학습 자료로 변환했다.
- 학습 19,696개, 별도 상황 검증 5,018개, 고정 제외 맵 검증 5,219개. 훈3/7.5/13/19는 가중치 업데이트에 쓰지 않았다.
- 4epoch의 짧은 학습 + 이어 학습 1epoch를 실제 CPU에서 실행했다. 모든 모델/자료는 로컬에 저장했다.
- 최종 별도 상황 위치 MAE 43.84px(상수 평균 기준 83.54px), 위험 Brier 0.0527(기준 0.1103).
- 제외 맵 위치 MAE 60.57px(상수 평균 기준 90.20px), 위험 Brier 0.0203(기준 0.0347).
- 모델이 채택되었고 `checkpoints/shared_physics_v1/active.pt`에 저장했다. 첫 사용자 실행은 이 가중치에서 이어 학습한다.
- 기존 DB 사본을 사용한 훈1 native 후보 8개 시험에서 7개 후보에 모델 점수가 기록됐다. 후보 요청 계획 8개 모두 저장됐고 실제 native 실행/기존 기록 유지가 확인됐다. 최단 기록은 51결정 그대로였다.
- 모델/인코딩 테스트 5개와 기존 수집기 테스트 12개 통과.
- 통합 실행기의 자료 백업 → 이어 학습 → 검증/모델 채택 → 정상 종료를 fit-only 1epoch로 확인했다.

모델이 학습된다는 증거와 실시간 게임을 잘한다는 증거는 다르다. 위 수치는 결과 예측 검증이며,
모델 안내가 무작위/기존 규칙보다 실제 맵을 더 잘 푼다는 대조 실험은 아직 하지 않았다.
최종 위치 오차가 여전히 수십 픽셀이므로 예측만으로 용암 통과 안전성을 보장할 수 없다.
모든 후보의 실제 판정은 원본 물리를 사용한다. 위험 라벨은 기존 복귀 추정기의 한계를 그대로 가진다.
