# 실시간 헬퍼 시범판

`Client.exe`에서 훈련용 LMF를 연 뒤, 이 폴더에서 실행합니다.

```powershell
python -u live_route_helper.py --act
```

- 게임 창이 앞에 있을 때 **F8**: 시작/일시정지, **F9**: 종료.
- **Shift를 누르거나 직접 게임 키를 누르는 동안** 헬퍼 입력을 놓고 수동 조작을 우선합니다.
- 공격은 기본적으로 꺼져 있습니다. 상대의 **플레이어 슬롯 번호를 직접 확인한 경우에만** `--combat priority --opponent-slot 1`처럼 실행합니다. **F7**로 공격을 켜거나 끌 수 있습니다.
- `--lmf "C:\...\훈1.LMF"`로 맵을 지정할 수 있습니다. 실제 클라이언트의 물체 기록과 정확히 일치하지 않으면 시작하지 않습니다.
- `--act`를 빼면 판단 로그만 출력하고 키를 누르지 않습니다.

현재 구현은 50ms 간격으로 상태를 읽고 9×9 지형에서 필요한 경우 시야를 넓힙니다. 보인 지형은 실행 중 기억하고, 깃발 방향 이동과 기존 금지키 규칙을 적용합니다. 주변을 평지·단절·벽·미확인으로 묶어 판단합니다. 발판이 이어지면 목표 방향으로 구르며, 현재 바라보는 방향에 따라 앞굴이나 뒷굴이 됩니다. 발판이 끊기면 먼저 점프하고, 공중의 진행 공간을 확인한 다음 공중 구르기를 후보로 둡니다. 공격은 측정한 평지 무기 사거리 안에서 `Z`를 누르고, 조금 먼 상대에게 안전한 구르기를 요청한 뒤 다음 판단에서 공격합니다.

이는 시범판입니다. 실제 클라이언트에서 아직 입력 반응 속도, 타격 성공률, 굴러가는 거리, 동적 장애물 대응을 검증하지 못했습니다. 로그의 `decision_ms`/`p95_ms`는 판단 한 번의 계산 시간이며 실제 타격까지 걸리는 시간은 아닙니다. 보이는 격자 외의 낙하 상대를 미니맵 화면으로 인식하지는 않으며, 지정한 상대 슬롯의 현재 좌표만 읽습니다. 학습은 이 프로그램이 시작하지 않습니다.
